# Markerless AR Dog Unity Project

A markerless Augmented Reality (AR) application developed using Unity and AR Foundation. The project displays a 3D German Shepherd dog in the real-world environment using an Android device camera without requiring image markers.

## 📱 Project Overview

This project demonstrates markerless AR using:

- Unity
- AR Foundation
- ARCore
- Android Camera
- 3D German Shepherd model

The dog is automatically created after a short delay and can follow the direction of the AR camera.

## ✨ Features

- Markerless Augmented Reality
- Android AR support
- Automatic dog placement
- No QR code or image marker required
- 3D German Shepherd model
- Dog follows the camera direction
- Dog rotates to face the camera
- Configurable placement distance
- Configurable appearance delay
- Single dog instance

## 🛠️ Technologies Used

- **Unity**
- **AR Foundation**
- **Google ARCore**
- **C#**
- **Android**
